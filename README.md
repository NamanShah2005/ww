# 📱 WhatsApp Chat Analyzer App

## 📌 Overview

This app dives deep into your WhatsApp conversations — whether it's your **group chats**, **one-on-one convos**, or **a few chosen friends** — and pulls out some wild stats. Built using Kotlin + Python (via Chaquopy), it offers detailed insights, trends, and a dash of surprise 👀

Created with love by **Naman Shah** 💻

---

## 🚀 Features

### 📊 Chat Analysis
- Full chat dump parsing (group, selected people, or single chats).
- Stats like:
  - Total messages
  - Most active participant
  - Media count (images, videos, stickers)
  - Word & emoji usage

### ⏰ Time-Based Insights
- Hourly activity
- Most chatty days
- Longest messages and average lengths

### 🔍 Deep Filters
- View media-only conversations
- Date-range and person-specific analysis

### 📈 Beautiful Charts
- Heatmaps, bar graphs, pie charts — you name it.
- Clean, minimal UI to interpret data effortlessly

---

## 🛠 Tech Stack

| Purpose              | Tech Used              |
|----------------------|------------------------|
| 📱 App Logic         | Kotlin (Android)       |
| 🧠 Data Analysis     | Python (via Chaquopy)  |
| 📁 File Handling     | Kotlin + Chaquopy      |
| 📊 Graphs            | MPAndroidChart         |
| 🧮 Data Computation  | Python (Pandas, Regex) |
| 🎨 UI/UX             | Android XML + Kotlin   |
